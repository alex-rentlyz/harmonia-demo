# Harmonia demo site

Static demo of a customer website (Harmonia event rentals) with the Rentlyz
website integration embedded: catalog, category filters, event date, cart and
checkout all run in the browser against the Rentlyz API.

Generated from `rentals_mobile/embed/demo-wordpress` with
`yarn embed:demo-export`. Do not edit the HTML by hand: change the theme or
demo content there and re-export.

- Hebrew: `/` · English: `/en/`
- Embed bundle: `embed/rentlyz.js`, `embed/rentlyz-app.js`
- Hosted with GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
